## 阶段 A：nas_data 零写入验证（只读操作）

### A1 准备固定夹具

在挂载中建立多级目录与跨块文件（此后到 A5 结束前不得改动）：

```bash
mkdir -p "$NAS_ROOT/电影" "$NAS_ROOT/音乐/专辑" "$NAS_ROOT/文档"
dd if=/dev/urandom of="$NAS_ROOT/电影/movie.mkv" bs=1M count=3    # 跨块
head -c 300000 /dev/urandom > "$NAS_ROOT/音乐/专辑/song.flac"
: > "$NAS_ROOT/文档/empty.txt"                                     # 空文件合法
sync
```

### A2 快照（启动服务之前）

```bash
find "$NAS_ROOT" -type f -printf '%P\t%s\t%T@\n' | sort > /tmp/msfile-before.list
find "$NAS_ROOT" -type f -print0 | sort -z | xargs -0 sha256sum > /tmp/msfile-before.sha
```

### A3 启动服务并等待首次扫描完成

```bash
for i in $(seq 1 60); do
  ready=$(curl -s "$ADMIN/api/status" | jq -r '.counts.ready_contents')
  running=$(curl -s "$ADMIN/api/status" | jq -r '.scan_running')
  [ "$running" = "false" ] && [ "$ready" = "3" ] && break
  sleep 1
done
curl -s "$ADMIN/api/files" | jq '.items[] | {seed_hash, recommended_filename, state}'
```

- [ ] 平面 Hash 列表不含绝对路径、不含目录树结构：______

按目标部署需要至少一条路径（WS / WSS / WebRTC Direct），客户端逐块重新计算

- [ ] Read(seed_hash) 返回 Seed，SHA-256 == seed_hash：______

### A5 停止服务

```bash

```

### A6 再次快照并比对

```bash
find "$NAS_ROOT" -type f -printf '%P\t%s\t%T@\n' | sort > /tmp/msfile-after.list
find "$NAS_ROOT" -type f -print0 | sort -z | xargs -0 sha256sum > /tmp/msfile-after.sha
diff /tmp/msfile-before.list /tmp/msfile-after.list || echo "FAIL: 列表不一致"

```

## 阶段 B：动态同步与失效恢复（会修改 nas_data）

> 本阶段每个用例都会改动 `nas_data`；如需保持最终态干净，
