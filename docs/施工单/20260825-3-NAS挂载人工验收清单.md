## 阶段 A：nas_data 零写入验证（只读操作）

### A1 准备固定夹具

在挂载中建立多级目录与跨块文件（此后到 A5 结束前不得改动）：

```bash
mkdir -p "$NAS_ROOT/电影" "$NAS_ROOT/音乐/专辑" "$NAS_ROOT/文档"
dd if=/dev/urandom of="$NAS_ROOT/电影/movie.mkv" bs=1M count=3    # 跨块
head -c 300000 /dev/urandom > "$NAS_ROOT/音乐/专辑/song.flac"
: > "$NAS_ROOT/文档/empty.txt"                                     # 空文件合法
sync
```

### A2 快照（启动服务之前）

```bash
find "$NAS_ROOT" -type f -printf '%P\t%s\t%T@\n' | sort > /tmp/msfile-before.list
find "$NAS_ROOT" -type f -print0 | sort -z | xargs -0 sha256sum > /tmp/msfile-before.sha
```

### A3 启动服务并等待首次扫描完成

> 推荐使用**独立空测试挂载**（只含 A1 的三个文件）。若复用已有数据的挂载，
> 则先在放入夹具前记录基线：`BASE=$(curl -s "$ADMIN/api/files?limit=200" | jq .total)`，
> 之后断言 `total == BASE + 3`。

```bash
for i in $(seq 1 60); do
  ready=$(curl -s "$ADMIN/api/status" | jq -r '.counts.ready_contents')
  running=$(curl -s "$ADMIN/api/status" | jq -r '.scan_running')
  [ "$running" = "false" ] && [ "$ready" = "3" ] && break
  sleep 1
done
curl -s "$ADMIN/api/files" | jq '.items[] | {seed_hash, recommended_filename, state}'
```

- [ ] 平面 Hash 列表不含绝对路径、不含目录树结构：______

### A4 只读操作：Stat / Read Seed / Read 每个块

使用验收客户端 `cmd/msfile-acceptance`（构建：`go build -o msfile-acceptance ./cmd/msfile-acceptance`）。
首次运行会打印 `client_public_key_hex=<...>`，把它加入服务端
`public_key_whitelist` 后重启服务。`ADDR` 取服务启动日志中带 `/p2p/` 的 multiaddr。

```bash
# Stat：输出 JSON（available/filename/size_bytes/media_type）
./msfile-acceptance --addr "$ADDR" --identity-key client.key stat --hash "$HASH"

# Read Seed 并强制校验 SHA-256(内容)==$HASH
./msfile-acceptance --addr "$ADDR" --identity-key client.key \
    read --hash "$HASH" --output seed.bin --verify

# verify-seed：额外校验长度 32 字节对齐并输出块数
./msfile-acceptance --addr "$ADDR" --identity-key client.key verify-seed --hash "$HASH"
```

- [ ] Stat 返回 available 且元数据正确：______
- [ ] Read Seed `--verify` 通过：______
- [ ] 对该文件的每一个 block_hash 执行 Read（可先 verify-seed 得到块数），
      SHA-256 全部匹配：______

### A5 停止服务

```bash
kill -TERM "$SERVICE_PID"   # 观察日志 nas_stopped，且进程在时限内退出
```

> 服务在本阶段结束时停止；阶段 B 开始前按 B0 重新启动。

- [ ] 进程有界退出（≤15s）：______

### A6 再次快照并比对

```bash
find "$NAS_ROOT" -type f -printf '%P\t%s\t%T@\n' | sort > /tmp/msfile-after.list
find "$NAS_ROOT" -type f -print0 | sort -z | xargs -0 sha256sum > /tmp/msfile-after.sha
diff /tmp/msfile-before.list /tmp/msfile-after.list || echo "FAIL: 列表不一致"
diff /tmp/msfile-before.sha  /tmp/msfile-after.sha  || echo "FAIL: 摘要不一致"
```

> 注：`.list` 文本快照无法可靠覆盖含换行符的文件名；
> **以 `.sha`（NUL 分隔）为主证据**，`.list` 仅辅助核对 mtime/尺寸。

- [ ] 两轮 diff 均为空（路径、数量、mtime、内容摘要完全一致）：______

### B4 目录临时不可见与恢复

> 默认扫描周期是 10 分钟，且挂载丢失时 watcher 事件不可靠，
> 因此必须**主动触发全量扫描**而不是等待固定时间。

```bash

  running=$(curl -s "$ADMIN/api/status" | jq -r '.scan_running')
  [ "$running" = "false" ] && break
  sleep 1
done

```

## 阶段 C：真实负载与资源证据（使用验收客户端）
